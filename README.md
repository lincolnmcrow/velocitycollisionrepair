# Velocity Collision Repair

Luxury / tough black, white and red website for Velocity Collision Repair and Hector Zuniga.

The site is built around truck collision repair and uses the provided truck photography in the local working copy.

## Launch checklist

- Add the five provided truck photos to the repository root using these filenames:
  - `truck-white.jpg`
  - `truck-repair.jpg`
  - `truck-blue.jpg`
  - `truck-damage.jpg`
  - `truck-black.jpg`
- If the exact logo asset is available, add it as `logo.png` and replace the text mark in the header.
- Add the shop phone, address and hours once confirmed.
- Connect the quote form to the preferred email or form service.
